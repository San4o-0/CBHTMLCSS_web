# Lab 2 — Основи CSS

Секція тарифних планів за технічним завданням ЛР-2: заголовок, опис і три картки тарифів.
Лише HTML і CSS, без JavaScript.

## Структура

```
Lab2/
├── index.html
├── styles.css
├── antipattern.html
├── research/
│   ├── box-model.html
│   ├── cascade.html
│   ├── cascade-external.css
│   ├── specificity.html
│   ├── inheritance.html
│   ├── variables.html
│   └── reuse.html
└── README.md
```

`research/` — сторінки для дослідницьких завдань 4.1–4.6.
`antipattern.html` — та сама секція, зверстана з типовими помилками, для порівняння з `index.html`.

## Локальний запуск

```bash
npx serve .
```
