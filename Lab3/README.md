# Lab 3 — Semantic HTML та SEO

Сторінка тарифних планів з ЛР-2 після аудиту й рефакторингу: семантична структура, ієрархія
заголовків, метадані, тексти, посилання та кнопки. Візуальна концепція ЛР-2 збережена.

## Структура

```
Lab3/
├── index.html
├── styles.css
├── research/
│   ├── div-structure.html
│   ├── semantic-structure.html
│   ├── headings-good.html
│   ├── headings-bad.html
│   ├── head-weak.html
│   ├── head-strong.html
│   ├── links-images.html
│   └── pricing.svg
└── README.md
```

`research/` — сторінки для мініекспериментів 4.1–4.4.

Cloudnest — вигаданий продукт. Форма в розділі Get started не має бекенду і нікуди не надсилає
дані.

## Локальний запуск

```bash
npx serve .
```
